# 微信公众号设计工作室

**WeChat Editorial Director** — an original content and visual-direction Skill for WeChat Official Account articles.

Most formatters start with a theme. This project starts with the article: diagnose the content, propose three genuinely different editorial directions, wait for the author to choose, then design layout and imagery as one coherent system.

## Signature workflow

1. Diagnose archetype, voice, emotional curve, evidence, and visual moments.
2. Present three structurally different art directions.
3. After direction selection, present three compatible color systems.
4. Choose whether the issue is evidence-, photography-, illustration-, diagram-, or hybrid-led; when generation is appropriate, present three compatible visual systems.
5. Let the author choose direction, palette, and visual system before final design begins, then create one style anchor, design recipe, and image plan.
6. Build an article-specific cover concept, reject generic category imagery, diagnose the draft, and refine-redraw it before testing 900×383 and center-square crops.
7. Compose a self-contained, copy-ready WeChat HTML deliverable without a simulated phone shell or default mobile screenshot.
8. Run a continuous prose pass for natural Chinese, then deliver the copy-ready article first, followed by the wide cover, square crop, and safe-area proof.

The goal is **continuity without sameness**: one publication identity, different editorial experiences for different articles.

Compatibility-sensitive visual components are flattened when needed. For example, a Safari-style project card is precomposed as a static image, while its simple CTA footer remains the only live link so WeChat cannot reflow the design.

The art-direction library includes a Scenic Portal option for image-led stories: one story-specific framing metaphor, a full-width atmospheric plate, and a narrow centered promise. Web-style layered video and glass effects are flattened into a WeChat-safe static image rather than copied as fragile HTML.

## Optional illustration companion

The studio can optionally consult [Smart Illustrator](https://github.com/axtonliu/smart-illustrator) for illustration-position auditing and Excalidraw/Mermaid diagram routing. It remains a separate dependency and does not replace this project's editorial direction, palette selection, dual-crop WeChat cover, or quality gates.
